JARVIS
======

1. Unzip this folder (example: C:\JARVIS)
2. Double-click RUN_JARVIS.bat
3. Talk to it

No API keys. First run downloads JARVIS's own free local brain
(SmolLM2, ~270 MB, once) and installs the engine automatically.
While that happens you can already open apps, find files, do maths,
and look things up.
