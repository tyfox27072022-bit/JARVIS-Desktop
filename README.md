# JARVIS — Windows desktop app

Native window (PySide6). Not a website.

1. Double-click **RUN_JARVIS.bat** (needs Python once), or
2. Double-click **BUILD_JARVIS.bat** → `dist\JARVIS\JARVIS.exe` + Desktop shortcut.

Settings: xAI key for fast Grok, or a local GGUF. Index a folder to learn files. Discord bot token for phone DMs.
